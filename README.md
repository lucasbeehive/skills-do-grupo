# Skills do grupo

Skills para o Claude (aplicativo no computador, aba Code), feitas para usar no dia a dia.

## Skills

| Skill | O que faz | Manual |
| --- | --- | --- |
| `assistir` | Assiste vídeos e áudios (fala e tela): resume com o minuto, varre o YouTube sobre um tema, pega a transcrição e transforma o que um vídeo ensina numa skill. | [Como usar a skill assistir.pdf](manuais/Como%20usar%20a%20skill%20assistir.pdf) |
| `modelo-certo` | O modelo forte da conversa planeja e cada agente roda no modelo mais barato que entrega a mesma qualidade (Haiku, Sonnet ou Opus; Fable só com motivo). | [Como usar a skill modelo-certo.pdf](manuais/Como%20usar%20a%20skill%20modelo-certo.pdf) |

## Instalar

No Claude, aba Code, cole:

```
Instala a skill <nome> seguindo as instruções de https://github.com/lucasbeehive/skills-do-grupo/blob/main/INSTALAR.md
```

Troque `<nome>` pelo nome da skill da tabela (por exemplo `assistir` ou `modelo-certo`).

O passo a passo completo, com cada programa que será baixado, está em [INSTALAR.md](INSTALAR.md).
